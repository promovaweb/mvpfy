# Modelo de preço

Use estas fórmulas quando os dados permitirem:

- custo mensal total = fixos + variáveis + IA + comunicação + suporte + taxas;
- margem por conta = receita líquida por conta menos custo variável por conta;
- contas para cobrir fixos = custos fixos divididos pela margem por conta;
- MRR = receita recorrente mensal normalizada das contas ativas;
- ARPA = MRR dividido pela quantidade de contas pagantes;
- churn = contas canceladas no período dividido pelas contas no início do período.

Apresente cenário enxuto, base e crescimento com premissas visíveis.

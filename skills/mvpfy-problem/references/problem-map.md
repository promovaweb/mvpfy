# Mapa do problema

Preencha:

| Campo | Pergunta simples |
| --- | --- |
| Situação | Quando isso acontece? |
| Pessoa | Quem sente o problema? |
| Tarefa | O que essa pessoa tenta fazer? |
| Dificuldade | O que impede o resultado? |
| Consequência | O que se perde ou fica mais difícil? |
| Alternativa | Como resolve hoje? |
| Limite | Por que a alternativa não basta? |
| Comprovação | Que relato, número ou observação sustenta a resposta? |

Use a frase: “Para [público], que precisa [tarefa], o problema é [dificuldade],
causando [consequência]. Hoje usa [alternativa], que falha por [limite]. O
MVP precisa verificar [hipótese].”

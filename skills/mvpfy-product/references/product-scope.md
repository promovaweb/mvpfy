# Matriz de escopo

| Classe | Uso na versão 1.0 |
| --- | --- |
| Essencial | Entrega a promessa central. |
| Operação | Sustenta conta, acesso, suporte, segurança ou cobrança. |
| Posterior | Pode esperar aprendizado real de uso. |
| Fora | Não sustenta o problema prioritário. |

Para cada recurso, informe entrada, processamento, saída, perfil autorizado,
regra principal e ligação com a jornada. Se não houver ligação clara, mova para
posterior ou fora.

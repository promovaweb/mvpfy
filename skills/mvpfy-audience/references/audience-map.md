# Mapa de público

| Papel | Pergunta |
| --- | --- |
| Segmento | Qual grupo sente o problema com maior frequência? |
| Usuário | Quem usa o software no dia a dia? |
| Titular | Quem cria e administra a conta? |
| Comprador | Quem compara opções e aprova a compra? |
| Pagador | Quem efetua o pagamento? |
| Beneficiário | Quem ganha com o resultado sem usar o produto? |

Uma persona deve conter contexto, tarefa, problema, alternativa atual, objeção,
gatilho de compra, canal e linguagem útil para a comunicação.

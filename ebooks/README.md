# Ebooks do MVPFy

Esta pasta publica a documentação completa do MVPFy em PDF e EPUB.

## Edição vigente

A versão está em [`VERSION`](VERSION). Os aliases estáveis são
[`ebook-mvpfy.pdf`](ebook-mvpfy.pdf) e [`ebook-mvpfy.epub`](ebook-mvpfy.epub).

Gere a edição com:

```bash
npm run ebook
```

Confira a edição sem gerar novos arquivos com:

```bash
npm run ebook:verify
```

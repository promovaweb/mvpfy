# Contribuição

Altere a skill especialista quando o novo conhecimento pertencer a um domínio.
Altere a orquestradora somente para regras de fluxo, retomada e integração.
Mudanças no template exigem atualização de `ebooks/VERSION`, testes de migração
e novo build do ebook.

Antes de abrir uma alteração, rode `npm test`, leia o `Company.md` de exemplo e
execute `npm run ebook:verify` quando a documentação tiver mudado.

# Seu primeiro MVP SaaS

O primeiro encontro começa pela situação problemática, não pelo nome da tela.
O agente pergunta quem sente a dificuldade, qual alternativa existe hoje e
qual resultado precisa funcionar do começo ao fim.

Depois, o plano conecta público, jornada, conta, onboarding, cobrança, suporte,
preço, custo, tecnologia, marketing e métricas. O escopo posterior fica
separado para manter a versão 1.0 pequena o bastante para aprender com os
primeiros clientes.

Quando fizer sentido, o plano recomenda Laravel em uma VPS, banco PostgreSQL,
armazenamento de arquivos, e-mail transacional e um provedor de IA apenas para
uma função clara do produto.

# Entrevista e retomada

O MVPFy lê o estado antes de cada turno. Uma resposta pode preencher várias
áreas e a próxima pergunta muda conforme o que já foi informado.

O fluxo é:

1. receber a resposta;
2. registrar o texto original e sua interpretação;
3. atualizar o estado e as seções afetadas;
4. confirmar a gravação;
5. apresentar uma única pergunta nova.

Você pode responder com o número de uma opção, escrever livremente, dizer que
não sabe, corrigir algo, pausar ou pedir uma área específica. Ao voltar, diga
“quero continuar meu MVPFy”. O agente retoma pela pendência mais importante.

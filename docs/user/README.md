# Guia do usuário

O MVPFy conduz uma conversa curta para estruturar uma empresa em formação e
seu primeiro SaaS. Você não precisa conhecer termos de produto, marketing ou
infraestrutura: a pergunta aparece com linguagem simples e a análise acontece
nas especialistas.

Comece por [instalação](instalacao.md), avance para o
[primeiro MVP](primeiro-mvp.md) e consulte a explicação da
[entrevista](entrevista.md) quando quiser entender a retomada.

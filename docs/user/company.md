# O arquivo Company.md

O `Company.md` é a entrega central. Ele não é uma transcrição: organiza o que
foi informado, o que foi recomendado, as hipóteses e as perguntas ainda abertas.

As seções cobrem resumo, empresa, problema, público, personas, marca, jornada,
conta, onboarding, escopo, módulos, assinatura, suporte, mercado, preço,
economia, tecnologia, operação, IA, website, marketing, vendas, métricas,
ameaças, execução, escolhas, hipóteses e fontes.

Uma versão parcial usa `document_status: preliminary`. O estado `ready` só
aparece após a presença dos campos mínimos do primeiro SaaS.

# Paleta do MVPFy

| Família | Base | Papel |
| --- | --- | --- |
| Petróleo | `#00161E` | estrutura, texto e superfícies escuras |
| Turquesa | `#2AD5BE` | degraus do plano e vínculo com a Promovaweb |
| Âmbar | `#F59E0B` | bandeira, meta alcançada e destaque |

O âmbar segue a escala `amber` do Tailwind CSS, com uma troca: o tom 600 é
`#B45309`, valor usado no logo para fundo claro. Os tons 700 a 950 descem a
partir dele. No light mode, use acento textual `#B45309`. No dark mode, use
`#FCD34D`. A escala completa e os estados ficam em `palette.json`; os pares
aprovados ficam em `../accessibility.md`.
